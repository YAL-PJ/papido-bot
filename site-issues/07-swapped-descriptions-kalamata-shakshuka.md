# 07 — תיאורים מוחלפים: קלמטה L ושקשוקה L

| | |
|---|---|
| חומרה | גבוהה (אלרגן) |
| איפה | טאביט — משלוח ואיסוף |

| סטטוס | פתוח |

## מה הבעיה
בקטגוריה "פיצות ניו יורק L":
- **פיצת קלמטה** מוצגת עם התיאור של השקשוקה: "רוטב עגבניות ופלפלים קלויים, בתוספת גבינת פטה וביצה עלומה"
- **פיצת שקשוקה** מוצגת עם התיאור של ההוואי: "רוטב אדום קלאסי, אננס, זיתי קלמטה, פלפל חלפניו…"

בגרסה האישית התיאורים נכונים.

## למה זה חשוב
לקוח שמזמין קלמטה L חושב שיש בה **ביצה**, ולקוח שמזמין שקשוקה L לא יודע שיש בה ביצה — בעיה לאלרגיים לביצים. וגם: לקוח מקבל פיצה שונה ממה שקרא.

## איך לתקן
בטאביט, בשני התפריטים: להעתיק את התיאורים מהגרסאות האישיות לגרסאות ה-L.

## הוכחה
משלוח: "פיצת קלמטה" ו"פיצת שקשוקה" בקטגוריה "פיצות ניו יורק L". איסוף: "פיצת קלמטה" ו"פיצת שקשוקה גדולה" — אותה טעות.
