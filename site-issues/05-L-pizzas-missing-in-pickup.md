# 05 — שתי פיצות L לא קיימות בתפריט האיסוף

| | |
|---|---|
| חומרה | גבוהה |
| איפה | טאביט — תפריט איסוף עצמי |
| נמצא | 2026-10-12 |
| סטטוס | פתוח |

## מה הבעיה
שתי פיצות לבנות קיימות במשלוח בשני גדלים, אבל באיסוף רק בגודל אישית:
- **פיצה בצל צרפתי** — במשלוח אישית 72₪ / L 117₪, באיסוף רק אישית 55₪
- **פיצה ירקות קלויים לבנה** — במשלוח אישית 72₪ / L 117₪, באיסוף רק אישית 55₪ (ראו גם 6)

## למה זה חשוב
לקוח שמגיע לאסוף לא יכול להזמין L של המנות האלה — לא באתר ולא בבוט. נראה מוזר ללקוחות ("רק במשלוח?").

## איך לתקן
בטאביט, בתפריט האיסוף: להוסיף את הגודל L לשתי המנות (90₪, כמו שאר הלבנות L באיסוף).

## הוכחה
סביר שתפריט האיסוף הועתק (בערך באמצע מרץ 2026) לפני שמנות ה-L האלה נוספו לתפריט המשלוח (בערך בתחילת מרץ). כדאי לבדוק אם חסרים עוד שינויים מאותה תקופה.
