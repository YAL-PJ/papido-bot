# 06 — "ירקות צלוים" באיסוף: אותה מנה בשם אחר?

| | |
|---|---|
| חומרה | בינונית |
| איפה | טאביט — תפריט איסוף עצמי |
| נמצא | 2026-10-12 |
| סטטוס | פתוח — צריך אישור של הבעלים |

## מה הבעיה
באיסוף יש מנה "ירקות צלוים" (רק L, 90₪) שלא קיימת במשלוח. במשלוח יש "פיצה ירקות קלויים לבנה" עם תיאור כמעט זהה. נראה שזו אותה פיצה בשם אחר, ועם שגיאת כתיב ("צלוים").

| | משלוח: פיצה ירקות קלויים לבנה | איסוף: ירקות צלוים |
|---|---|---|
| תיאור | רוטב לבן, חציל קלוי, פלפלים קלויים, פורטובלו, פסטו עגבניות מיובשות, גבינת עזים, פטרוזיליה | חציל צלוי, קישוא, פלפלים קלויים, פורטובלו, פסטו עגבניות מיובשות, גבינת עיזים |

## למה זה חשוב
לקוח שמחפש את הפיצה באיסוף לא ימצא אותה בשם המוכר. אם זו אותה מנה — יש שתי גרסאות מתכון (קישוא מול פטרוזיליה).

## איך לתקן
אם זו אותה מנה: לשנות את השם באיסוף ל"פיצה ירקות קלויים לבנה" ולהשוות תיאור. אם לא — לתקן את הכתיב ל"ירקות צלויים".

## הוכחה
מוצר "ירקות צלוים", קטגוריה "פיצות לבנות L" בתפריט האיסוף בלבד.
